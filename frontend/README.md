# HorizonStay Frontend

This directory contains the React and TypeScript client for the HorizonStay Hotel Management System.

For complete project setup, Docker instructions, demo accounts, backend documentation, and test commands, see the [main project README](../README.md).

## Development

```bash
npm ci --legacy-peer-deps
npm run dev
```

The development server runs at <http://localhost:5173> and uses `VITE_API_URL` as the backend API base URL.

## Validation

```bash
npm run lint
npm run build
```
